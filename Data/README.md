# Experimental Data 

Physical bench measurements acquired via digital storage oscilloscopes and automated SCPI test benches:

* **`Data/AC`**: Calibrated time-domain AC voltage captures across various frequency and reactive network configurations, along with global parameter extraction scripts.
* **`Data/DC characteristics`**: Quasi-static $I-V$ sweeps documenting threshold voltage shifts ($\alpha$), soft-knee curvature ($R_k$), and plateau resistance ($R_p$).
