# Real-time virtual analog models implementing the nonlinear dipole equations:

* **`Juce Plugin`**: Production-ready audio plugin targeting VST3, CLAP, LV2, and Standalone with bundled impulse responses (IRs) and hardware-level GUI monitoring.
* **`Faust`**: Compact mathematical DSP description and architecture wrappers (*Work in Progress*).
* **`JesuSonic`**: Script-based JSFX implementation for Cockos REAPER (*Work in Progress*).
